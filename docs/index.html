VeilGrid

Private, serverless location sharing. No account, no sign-up — just link contacts by QR.

Download for Android

APK · Android 8 and newer · iPhone isn’t supported yet

How to install

  1. Tap the button above and wait for the download to finish.
  2. Open the file. Android asks to allow installs from your browser (or Files) — allow it, then tap Install.
  3. Open VeilGrid and allow location access. On the second screen choose Allow all the time, otherwise sharing stops when the app is in the background.
  4. Add people: Contacts → Add contact, then scan their QR code (or paste their code).

Updates

The app updates itself. Open Settings → Check for updates and install when a new version is offered — no store needed.

Privacy

Locations travel directly between devices over Veilid, and history stays encrypted on the phone. There are no accounts and no analytics. Two things do leave the device: map tiles and the text you type into place search.
