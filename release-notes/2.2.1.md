VeilGrid 2.2.1 is the first standalone release (no longer a Grid fork).

New in this build:
- New app identity (app.thalionn.veilgrid). This is a fresh install: link contacts again with a QR code.
- In-app updates from GitHub Releases (Settings -> Check for updates).
- Serverless peer-to-peer sharing over Veilid with QR contact linking.
- Signed, allowlisted location messages; contact removal and address rotation.
- Places with address search, radius circles on the map, who's there, and movement alerts.
- Contact history with a 7-day trail, home geofence, and per-contact pause.
- No accounts or analytics; history is encrypted on device; cloud backup disabled.

Notes:
- Map tiles still load from map.mygrid.app.
- Android asks you to allow installs from VeilGrid the first time you update.
