VeilGrid 2.3.0 — much smaller download.

- The APK is now ~61 MB instead of ~179 MB. Releases ship only the 64-bit
  ARM libraries (every phone that runs this app uses them) and the app no
  longer bundles unused assets.
- Removed roughly thirty plugins inherited from the original app (Firebase,
  UnifiedPush, Play Billing, image picker/cropper, share, webview, the old
  flutter_map stack, lottie and others). VeilGrid no longer requests Billing
  or push permissions and no longer exposes their services and receivers.
- Deleted dead screens, widgets and the leftover database tables.
- No behaviour changes: same map, places, history, movement alerts and
  updates.
