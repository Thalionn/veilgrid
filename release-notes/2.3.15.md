VeilGrid 2.3.15 — much lower background drain.

While the app is hidden and the phone is still, the Veilid node now parks
itself instead of staying fully attached. A full node keeps ~32 peer
connections and continuous DHT/route upkeep, which measured about 23% of one
CPU core even with nothing to do.

- After 5 minutes still in the background the node detaches, and wakes for a
  30-second sync window every 5 minutes to publish the current route and pick
  up messages. Scheduled location sends run inside their own short window.
- Movement (leaving a still spell, or driving speed) and reopening the app
  wake it immediately, so live updates are unchanged while you are using it or
  on the move.
- Trade-off: while parked with the screen off, incoming positions can be up to
  about 5 minutes old, and sending pauses between windows.
- Idle CPU in the same test fell from ~23% to ~2.5% of one core.
- Battery diagnostics gains a per-minute VEILID line: attachment state, live
  peers, throughput, and whether the node is parked.
- The unused Veilid API log stream is disabled; nothing consumed it.
