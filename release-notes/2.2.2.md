VeilGrid 2.2.2 — first public release.

- New app icon: a mint location pin with a grid cut into it (plus a matching
  launch splash).
- Release builds now use the Android keystore for the identity key instead of
  falling back to an unencrypted on-disk store; R8 was stripping the crypto
  classes and the build was pulling the wrong Tink artifact.
- In-app updates from GitHub Releases (Settings → Check for updates).
- New package name (app.thalionn.veilgrid): Android treats VeilGrid as a
  separate app, so this is a fresh install and existing Grid installs cannot
  be updated in place — link contacts again with a QR code.
- Serverless peer-to-peer sharing over Veilid; signed, allowlisted location
  messages; contact removal and address rotation.
- Places with address search (OpenStreetMap), radius circles on the map,
  presence, and movement alerts; contact history; home geofence with
  auto-pause on arrival.
