VeilGrid 2.2.2 — first public release.

- New app icon: a mint location pin with a grid cut into it (plus a matching
  launch splash).
- Release builds now genuinely use the hardware-backed keystore for the
  identity key — fixed the R8/Tink packaging that silently fell back to an
  unencrypted key store.
- In-app updates from GitHub Releases (Settings -> Check for updates).
- New app identity (app.thalionn.veilgrid): this is a fresh install, so link
  contacts again with a QR code.
- Serverless peer-to-peer sharing over Veilid; signed, allowlisted location
  messages; contact removal and address rotation.
- Places with address search, radius circles on the map, presence, and
  movement alerts; contact history; home geofence.
