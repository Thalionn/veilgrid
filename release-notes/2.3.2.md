VeilGrid 2.3.2 — hardening pass, much smaller download.

- The APK is now ~61 MB instead of ~179 MB: releases ship only the 64-bit
  ARM libraries, and unused plugins and assets are gone.
- The updater checks that a downloaded APK is signed by the same certificate
  as the installed app (and has the right package name) before handing it to
  Android's installer.
- Update downloads live in their own cache folder, and the app's file
  provider exposes only that folder.
- Contact addresses in log lines are truncated, and GPS coordinates are no
  longer printed.
- The CI workflow's GitHub token is now read-only.
- Updated the packages that could be updated safely (QR scanner, shared
  preferences, geolocator, google_fonts, permission_handler, latlong2).
