VeilGrid 2.3.2 — hardening pass.

- The updater now checks that a downloaded APK is signed by the same
  certificate as the installed app (and has the right package name) before
  handing it to Android's installer.
- Update downloads live in their own cache folder, and the app's file
  provider exposes only that folder.
- Logs no longer include full contact addresses or GPS coordinates.
- CI now runs with a read-only token.
- Updated the packages that could be updated safely (QR scanner, shared
  preferences, geolocator, google_fonts, permission_handler, latlong2).
- Build output no longer includes a stale generated plugin registrant.
