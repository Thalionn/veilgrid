VeilGrid 2.3.13 — the low-power tier actually takes effect.

- When tracking switches to the low-power tier while stationary, the native
  tracker is restarted so Android replaces the old high-accuracy GPS request
  with the passive low-power provider. Previously the preset changed, but the
  high-accuracy listener stayed registered.
- A stationary, screen-off check after the fix recorded no GPS and no Wi-Fi
  use instead of continuous GPS.
- Battery diagnostics remains available in Settings → Battery & tracking for
  live activity, preset, fix and send logging.
